# Aura Pilates

Aura Pilates, pilates eğitmenlik programları ve stüdyo dersleri için hazırlanmış
bir demo web uygulamasıdır.

## Geliştirme

Node.js ve Bun kurulumundan sonra:

```sh
bun install
bun run dev
```

Üretim derlemesi için `bun run build`, testler için `bun run test` komutlarını
kullanın.
