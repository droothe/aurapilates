# Aura Pilates

Aura Pilates, pilates eğitmenlik programlarını ve stüdyo derslerini tanıtan bir web uygulamasıdır. Eğitim programları ve takvim görüntülenebilir, ilgilenenler başvuru formunu kullanabilir. Yönetim ekranları eğitimleri ve başvuruları düzenlemek için kullanılır.

## Geliştirme

Gereksinimler: [Bun](https://bun.sh/)

```sh
bun install
bun run dev
```

Üretim derlemesi için `bun run build`, testler için `bun run test` komutlarını kullanın.

## Teknolojiler

React, TypeScript, Vite, TanStack Router ve Supabase tabanlı sunucu işlevleri kullanılır.
